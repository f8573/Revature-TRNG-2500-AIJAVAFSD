# Day 4 Exception and File Handling

**Batch:** Ashu Jauhari

This folder contains the Student Result Portal exception-handling lab, the employee object-serialization exercise, and concise answers to the exception interview questions.

## Student Result Portal

Open `StudentResultPortal` in a terminal, then compile and run:

```text
javac *.java
java Main
```

The program demonstrates the five repairs, both custom exceptions, and a `finally` block for successful, low-attendance, and invalid-mark cases. See `StudentResultPortal/Reflection_Answers.md` for the exercise reflections.

## Employee serialization

Open `FileHandling` in a terminal, then compile and run:

```text
javac *.java
java EmployeeSerializationDemo
```

This writes the five employee objects to `employees.dat`, reads the array back, and prints each employee.
