# SmartStore Copilot Lab Solution

- `src/com/smartstore/billing/BillingApplication.java` is the refactored SmartStore program.
- `src/com/smartstore/billing/BillingApplicationOriginal.java` is the initial version used for the output comparison.
- `src/com/smartstore/billing/SalaryCalculator.java` completes the independent employee-salary challenge.
- `test/com/smartstore/billing/` contains 20 JUnit 5 tests across the billing and salary challenges.
- `Prompt_Log.md` records each lab exercise, prompt, result, changes, and verification.

JUnit Jupiter is included at `lib/junit-platform-console-standalone-1.14.4.jar` and referenced by both VS Code and Eclipse project settings. Open the repository or this lab folder in VS Code, then run **Java: Clean Java Language Server Workspace** and reload if the imports remain unresolved.
