# CityPower Prompt-Writing Assignment Solution

- `src/com/citypower/billing/ElectricityBillApplication.java` is the refactored final application.
- `src/com/citypower/billing/ElectricityBillApplicationOriginal.java` is the initial version used for the before/after output comparison.
- `test/com/citypower/billing/ElectricityBillApplicationTest.java` contains 17 JUnit 5 tests.
- `Prompt_Log.md` contains the prompt log, review decisions, and completed 10-row test sheet.

JUnit Jupiter is included at `lib/junit-platform-console-standalone-1.14.4.jar` and referenced by both VS Code and Eclipse project settings. Open the repository or this lab folder in VS Code, then run **Java: Clean Java Language Server Workspace** and reload if the imports remain unresolved. The green JUnit screenshot is saved as `junit_green.png` in this folder.
